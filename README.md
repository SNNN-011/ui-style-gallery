# UI Style Gallery — 85 halaman demo

Galeri 85 style UI dari ui-ux-pro-max (styles.csv), satu halaman per style.
Tiap halaman pakai layout archetype berbeda (bento, brutal, dashboard, editorial,
glass, HUD, terminal, mobile, poster, dll) + komponen signature (toggle, gauge,
heatmap, funnel, pricing, chat, dll) — jadi bedanya struktural, bukan cuma font.

- index.html  -> galeri dengan filter pencarian
- styles/     -> 85 halaman demo (style-01 ... style-85)
- gen_style_gallery.py -> generator (bisa di-edit lalu di-re-run)

Buka: buka index.html langsung di browser, atau `python -m http.server`.
